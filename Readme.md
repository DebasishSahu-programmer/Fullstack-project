# 🎬 VideoTube

A full stack video sharing platform built with the MERN stack.

---

## 🚀 Live Demo

🔗 **[https://fullstack-project-frontend-damd.onrender.com](https://fullstack-project-frontend-damd.onrender.com)**

## 🛠️ Tech Stack

### Frontend
- **React 19** — UI library for building interactive interfaces
- **React Router 8** — Client side routing and navigation
- **Redux Toolkit** — Global state management for auth, videos, comments
- **Tailwind CSS 4** — Utility first styling with dark/light theme
- **Axios** — HTTP client for API calls
- **Vite** — Fast build tool and dev server

### Backend
- **Node.js** — JavaScript runtime environment
- **Express.js** — Web framework for REST API
- **MongoDB** — NoSQL database for storing users, videos, comments
- **Mongoose** — ODM for MongoDB schema and queries
- **JWT** — Stateless authentication with access and refresh tokens
- **Cloudinary** — Cloud storage for videos and images
- **Multer** — Middleware for handling file uploads
- **Bcrypt** — Password hashing for security

---

## ✨ Features

- 🔐 **Authentication** — Secure register and login with JWT stored in HTTP only cookies
- 🎥 **Video Upload** — Upload videos with thumbnail to Cloudinary
- 🔍 **Search** — Search videos by title or description
- 👍 **Likes** — Like and unlike videos and comments
- 💬 **Comments** — Add, edit and delete comments on videos
- 📺 **Subscriptions** — Subscribe and unsubscribe to channels
- 👤 **Channel Profile** — View channel with subscriber count and uploaded videos
- 🖼️ **Image Upload** — Update avatar and cover image anytime
- 🌙 **Theme Toggle** — Switch between dark and light mode
- 📱 **Responsive** — Works on mobile, tablet and desktop
